# Universe Platform Template (Static)

這是一個可直接部署到 GitHub Pages 的靜態平台模板（首頁 / 線上抽牌 / AI 直播塔羅占卜間 / 牌庫 / 單張牌頁）。

## 檔案
- index.html
- draw.html
- deck.html
- card.html
- styles.css
- data.js
- app.js

## 使用
1. 直接開啟 index.html
2. 或用 VS Code + Live Server
3. 上線：GitHub Pages（main / root）

## AI 直播占卜間（draw.html#live）
- 模擬「直播中」狀態與聊天室滾動留言
- 觀眾可輸入問題、選牌陣、選解讀語氣
- AI 主播會即時抽牌並輸出結構化解讀（重點 / 總結 / 24 小時行動）
- 可先當 MVP，上線後再接真實 LLM API
